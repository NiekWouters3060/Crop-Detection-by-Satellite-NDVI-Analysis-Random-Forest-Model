# Crop-Detection-by-Sattelite-NDVI-Analysis-Random-Forest-Model
Detect what crop was grown on fields in the region of Bertem, Belgium in a certain year. Based on the NDVI data collected from Copernicus Satellite program of the field in that year, a Random Forest model will predict the crop grown.
Data from copernicus combined with https://app.watchitgrow.be/ and physicical observatory for the crop data.
